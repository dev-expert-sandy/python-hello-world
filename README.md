
# Python Hello World

A simple Python application demonstrating basic Python execution and GitHub source-code management.

## Application

The project contains a Python script named `hello.py`.

The application prints a welcome message and a second message indicating that the project is managed using VS Code and Git.

## How to run

Make sure Python is installed on your machine.

Run the following command from the project directory:

python3 hello.py

## Expected output

Hello, World!
This project is now being managed using VS Code and Git!
